# Acme 社内販売管理システム (example)

これはコンテキストパックの書き方を示すサンプルである。実際の導入では、対象システムを
運用している組織がこの形式で知識を提供する。差し替えて使うこと。

## この画面群の位置づけ

社内の受注入力システム。営業担当が客先からの注文を登録し、承認を経て出荷指示に回す。

## 用語

- **仮伝票**: まだ承認されていない受注。保存しても在庫は引き当てられない
- **本伝票**: 承認済みの受注。この時点で在庫が引き当てられる
- **区分コード**: 画面上は数字だけが出るが、意味は 10=通常 / 20=返品 / 90=社内消費

## 操作上のルール

- **「確定」ボタンは承認者だけが押す。** 営業担当は「保存」で止め、承認待ちにする。
  営業担当が確定を押すと差し戻しに半日かかる
- 顧客コードが不明な場合は空欄のままにせず、必ず `99999`（未登録）を入れる。
  空欄で保存すると翌日のバッチが落ちる
- 単価は税抜で入れる。画面のラベルは「単価」としか書いていないが税抜が正しい

## よくある詰まり

- 「保存できません」とだけ出る場合、ほぼ納期欄が過去日付になっている
- 区分コード 20（返品）のときだけ、元伝票番号の入力が必須になる。
  画面には必須マークが出ないが、入れないと確定時に弾かれる
